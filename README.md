# .github

Organization-level defaults for [Nomploy](https://github.com/Nomploy).

| Path | What it does |
|---|---|
| [`profile/README.md`](profile/README.md) | The page shown at [github.com/Nomploy](https://github.com/Nomploy). |
| [`profile/assets/`](profile/assets) | Brand assets referenced by that page. |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Default contributing guide. |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Default code of conduct. |
| [`SECURITY.md`](SECURITY.md) | Default security policy and disclosure address. |
| [`SUPPORT.md`](SUPPORT.md) | Where to ask for help. |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE) | Default issue forms. |
| [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) | Default pull request template. |

GitHub falls back to these files for any repository in the organization that
does not ship its own copy. A repository with its own `CONTRIBUTING.md`,
`SECURITY.md` or issue templates — [nomploy](https://github.com/Nomploy/nomploy)
does — always wins; nothing here overrides it.

Edits to `profile/README.md` are live as soon as they land on `main`.
