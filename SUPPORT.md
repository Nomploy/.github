# Support

## Documentation first

Most questions are answered in the docs: **[docs.nomploy.com](https://docs.nomploy.com)**,
starting with the [installation guide](https://docs.nomploy.com/docs/core/installation).

## Asking a question

- **Something is broken** — open an issue on the repository it affects, with the
  version, your install method, and logs.
- **Something is missing** — open a feature request describing the problem you
  hit, not only the solution you have in mind.
- **A pack you need doesn't exist** — open an issue on
  [nomad-packs](https://github.com/Nomploy/nomad-packs/issues), or send a PR.
- **Anything else** — [contact@nomploy.com](mailto:contact@nomploy.com).

## Please don't

Report security vulnerabilities publicly. Email
[contact@nomploy.com](mailto:contact@nomploy.com) instead — see
[SECURITY.md](SECURITY.md).

## Response times

Nomploy is maintained by a small team. Issues with clear reproduction steps get
answered fastest, and pull requests fastest of all.
